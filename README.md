# High-Performance Data Manipulation Pipeline using R data.table

## Project Overview

This project demonstrates high-performance data manipulation using the **data.table** package in R. It simulates a transactional sales dataset, performs efficient data loading, indexing, memory-efficient column updates, and analytical aggregations.

The project highlights techniques commonly used in large-scale data processing and business analytics.

---

## Objectives

- Generate a transactional sales dataset.
- Load and process data efficiently using `fread()`.
- Improve query performance with `setkey()`.
- Perform in-place column updates using `:=`.
- Calculate discounts and final sales amounts.
- Generate customer-wise revenue summaries.
- Export processed datasets for reporting.

---

## Technologies Used

- R 4.6.1
- data.table 1.18.4

## Dataset

The project creates a sample dataset containing **10,000 transactional records** with the following columns:

| Column | Description |
|---------|-------------|
| CustomerID | Customer identifier |
| Product | Product purchased |
| Quantity | Number of items |
| Price | Unit price |
| TotalAmount | Quantity × Price |
| Discount | 10% discount |
| FinalAmount | Amount after discount |

---

## Features Implemented

### 1. Data Generation

Creates a transactional dataset using random customer IDs, products, quantities, and prices.

### 2. Fast File Reading

Uses

```R
fread()
```

to efficiently load CSV files.

---

### 3. Fast Searching using setkey()

```R
setkey(sales, CustomerID)
```

Creates an index on `CustomerID` to enable faster lookups.

Example:

```R
sales[J(1010)]
```

---

### 4. Memory-Efficient Updates

Uses `:=` to add new columns without copying the dataset.

```R
sales[, Discount := TotalAmount * 0.10]
sales[, FinalAmount := TotalAmount - Discount]
```

---

### 5. Customer Revenue Analysis

Calculates total revenue generated by each customer.

```R
sales[, .(
Revenue = sum(FinalAmount)
), by = CustomerID]
```

Ranks customers by revenue.
